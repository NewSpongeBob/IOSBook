S03

网络安全与信任配置

安全传输、证书信任与服务端授权的职责划分

TLS 保护传输通道，但不替代身份认证、对象级授权、服务端输入校验或密钥管理。网络安全评估应同时关注客户端与服务端责任。

防御基线

  • 使用系统网络 API 和现代 TLS 配置，避免自定义加密协议。
  • 正确验证服务端身份；证书轮换和故障处理应有明确运维方案。
  • 服务端对每个敏感操作执行认证、授权、参数校验与速率控制。
  • 避免在 URL、日志和分析事件中泄露令牌或敏感数据。

验证计划

在自有测试环境检查正常、过期凭据、权限不足、网络失败和服务端错误路径。记录客户端/服务端版本、测试证书和预期结果；不对第三方服务执行拦截或探测。
