隐私权限与用户同意

权限请求是产品数据治理的一部分，而不只是系统弹窗

系统授权只表示特定 API 在当前条件下可访问，不代表用户同意任意用途或长期收集。应用仍需遵守目的限制、最小化和透明原则。

设计流程

  1. 先确认功能是否真的需要敏感数据；尽量提供不授权也可使用的替代体验。
  2. 在请求前说明具体用途，确保描述与实际数据处理一致。
  3. 处理拒绝、撤销、受限状态和设备策略限制；不要循环施压要求授权。
  4. 收集最少数据，设定保存期限和删除机制。

验证

在自有测试应用中分别验证首次请求、允许、拒绝、撤销和受限状态。检查日志、分析事件和服务端是否只收到确有必要的数据。
