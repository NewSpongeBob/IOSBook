R08

运行时观察与测试策略

用自有样例验证运行时假设，并把实现细节和契约分开

调试器、测试、日志和性能分析工具能提供运行时证据，但每种观测都有扰动、权限和版本限制。观察到的行为不自动成为平台保证。

实验记录

  • 写明问题、假设、反例条件与预期结果。
  • 记录源代码提交、构建配置、编译器、SDK、架构和系统版本。
  • 使用自有最小程序隔离变量；一次实验只改一项关键因素。
  • 分别标注语言语义、公开 API 契约、ABI 承诺、实现观察和推断。

适合的工具类别

XCTest 验证功能契约；Instruments 分析性能和生命周期；调试器检查自有进程状态；编译器输出与公开源码帮助理解生成结果。避免把工具显示格式当成真实内存布局的权威来源。

测试金字塔

  1. 单元测试覆盖类型、错误、nil 和状态转换。
  2. 集成测试覆盖 Swift/Objective-C 模块边界。
  3. 设备矩阵验证架构、OS 和优化配置差异。
  4. 发布回归确认性能与崩溃率没有退化。
