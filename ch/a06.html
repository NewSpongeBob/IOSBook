A06

自测题与参考答案

用解释和边界条件检查是否建立了系统模型

问题

  1. 为什么代码签名不能证明应用业务逻辑安全？
  2. Mach task/thread 与常见进程/线程术语为什么不能简单混为一谈？
  3. 文件偏移、虚拟地址和运行时地址分别描述什么？
  4. 为什么客户端隐藏 UI 不能代替服务端对象级授权？
  5. 发现测试目标包含真实用户数据时应如何处理？

参考要点

  1. 签名关联身份与完整性，不证明逻辑正确、授权正确或后端安全。
  2. 它们属于不同层次的系统抽象；具体映射依赖平台 API 和实现，不应凭名称假定等价。
  3. 文件偏移是磁盘文件位置，虚拟地址是映像地址空间概念，运行时地址是进程实际映射后的地址；转换需结合加载信息和随机化。
  4. 客户端运行在用户可控制环境，UI 可被改变；服务端必须验证当前主体对目标资源的权限。
  5. 立即停止、隔离数据、避免复制传播，按授权和组织的数据处理/事件流程报告。

延伸方法

为每个答案补充来源、适用版本、一个可验证的自有样例和一个可能使结论失效的边界条件。无法确认的细节应写“未知”，不要臆测。
