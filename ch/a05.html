A05

安全审查清单

以问题驱动审查；清单不能替代威胁建模和代码审查

身份与授权

  • 敏感操作是否由服务端验证身份、资源归属和权限？
  • 登出、过期、撤销和账户切换是否能使旧会话失效？
  • 客户端是否错误地把隐藏按钮、设备标识或本地标志当成授权？

数据与隐私

  • 每类敏感数据是否有目的、最小采集和删除期限？
  • 凭据是否采用合适的平台存储与访问控制，日志是否脱敏？
  • 锁屏、备份、恢复、崩溃和分析路径是否纳入检查？

平台与构建

  • 能力和 API 是否公开、获准且在目标 OS 范围受支持？
  • 依赖、构建脚本、签名凭据和发布产物是否可追溯？
  • 错误与离线状态是否安全降级，关键版本是否回归？

研究与交付

  • 测试是否有明确书面授权，使用隔离环境和虚构数据？
  • 报告是否区分事实、推断和未知，且不泄露敏感材料？
  • 修复是否有自动化测试、版本范围和回滚方案？

每项标记：通过 / 不适用 / 待处理，并附证据、负责人和复查日期。
